# Hospital/Clinic Management System

## 1. Case Study Description

The Hospital/Clinic Management System is a database system designed to manage patient information and daily medical activities in a hospital or clinic. It helps healthcare workers organise patient records and access medical information when needed.

The system stores information about patients, doctors, appointments, diagnoses, prescriptions, and laboratory records.

## 2. Purpose of the System

The purpose of the system is to make hospital record management easier, improve the organisation of medical information, and support the retrieval of patient medical history. It also helps hospital staff manage appointments and maintain accurate medical records.

## 3. Users of the Database

The main users of the system are:

- **Receptionists:** Register patients and book appointments.
- **Doctors:** View patient histories, record diagnoses, and prescribe medicines.
- **Laboratory staff:** Record laboratory tests and results.
- **Authorised hospital administrators:** Manage relevant patient, doctor, and appointment information.

## 4. Major Data to Be Stored

The database will store:

- **Patient records:** Patient ID, name, date of birth, gender, and contact information.
- **Doctor records:** Doctor ID, name, specialisation, and contact information.
- **Appointment records:** Appointment ID, patient, doctor, date, time, and status.
- **Diagnosis records:** Diagnosis ID, appointment, diagnosis description, and date.
- **Prescription records:** Prescription ID, diagnosis, medicine, and dosage.
- **Laboratory records:** Laboratory record ID, patient, test name, test date, and result.

## 5. Key Operations Supported

The system will support the following operations:

1. Register and store patient information.
2. Book and manage appointments with doctors.
3. Record diagnoses after consultations.
4. Store prescription information.
5. Record laboratory tests and results.
6. Retrieve a patient's medical history when authorised.

## 6. Expected Benefits

The system is expected to improve the organisation of hospital records, reduce unnecessary duplication of information, make patient history easier to retrieve, and support more efficient appointment management.

## 7. Scope

This project focuses on designing a database for patient and medical record management. It will use the Hospital/Clinic Management System as the case study for database design, SQL query optimisation, transactions and concurrency, NoSQL modelling, and distributed or cloud database exercises.
